Project

Smart Sort — Waste Segregation System

SIH Round 3 Qualified

A project built for the Smart India Hackathon to automate solid waste sorting at the point of disposal using computer vision and mechanical diverters.

Context

India generates massive quantities of municipal solid waste daily, but the majority ends up unsegregated in landfills. This makes recycling difficult, pollutes soil and groundwater, and creates unsafe manual sorting conditions.

Automating segregation directly when waste is thrown helps separate wet, dry, and recyclable items before they contaminate each other.
