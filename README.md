# Portfolio

Personal portfolio website built with HTML, Tailwind CSS, and vanilla JavaScript.

---

## Overview

A responsive single-page portfolio highlighting projects, technical skills, and background.

- Built without heavy frontend framework dependencies.
- Styled using Tailwind CSS via CDN.
- Fully responsive layout for mobile and desktop.

---

## Running Locally

Open `index.html` directly in your web browser, or serve it using Python:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
